## [Physics Agent]({{ '/projects/physics-agent/' | relative_url }})

A physics problem-solving agent built around local LLM inference. It uses Qwen through Hugging Face Transformers on GPU compute to work with problem text and diagrams, with structured answers and checkpoints for each run.
