# Projects

## [Physics Agent]({{ '/projects/physics-agent/' | relative_url }})

A physics problem-solving agent built around local LLM inference. It uses Qwen through Hugging Face Transformers on GPU compute to work with problem text and diagrams, with structured answers and checkpoints for each run.

## [Musical Embeddings]({{ '/projects/musicAI.html' | relative_url }})

Exploring song similarity with EnCodec audio embeddings and Dynamic Time Warping, with a Gradio app for comparing tracks.

## [SolPPC]({{ '/projects/SolPPC.html' | relative_url }})

A Rust command-line client for a Solana-based protocol that connects API payments with access to microservices.
